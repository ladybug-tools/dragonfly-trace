dragonfly_trace.exp module¶

Methods to generate EXP templates for Trane TRACE.

dragonfly_trace.exp.airflow_from_exp(exp_str)[source]¶

“Get Infiltration, Ventilation and ExhaustAir from TRACE 700 AirflowTemplate.

Parameters:

exp_str – A TRACE 700 AirflowTemplate entry string.

Returns:

A tuple with three elements.

  • infiltration: A Honeybee Infiltration object if the infiltration is non-zero and defined per exterior area. None otherwise.

  • ventilation: A Honeybee Ventilation object if ventilation is non-zero and is either “Sum of Outdoor Air” or “ASHRAE 62.1.” None otherwise.

  • exhaust: A Honeybee ExhaustAir object if exhaust air is non-zero and defined per floor area or as an absolute flow rate. None otherwise.

dragonfly_trace.exp.airflow_to_exp(program, si_units=False, ventilation_method='Sum of Outdoor Air')[source]¶

Get an EXP string containing only the airflow template for a ProgramType.

Parameters:

  • program – A Honeybee ProgramType object.

  • si_units – Boolean to note whether the units of the values in the resulting matrix are in SI (True) instead of IP (False). (Default: False).

  • ventilation_method –

    Optional text for the ventilation method to be used in the airflow template. Choose from the following.

    • Sum of Outdoor Air

    • ASHRAE 62.1

Returns:

Text string of an EXP file for TRACE 700 containing the airflow template.

dragonfly_trace.exp.equipment_to_exp(equipment, si_units=False, watts_per_area=None)[source]¶

Get a TRACE 700 “T.LOAD_MISEQUIP” entry string from a Honeybee Equipment object.

Parameters:

  • equipment – A Honeybee ElectricEquipment or GasEquipment object.

  • si_units – Boolean to note whether the units of the values in the resulting matrix are in SI (True) instead of IP (False). (Default: False).

  • watts_per_area – Optional float for total W/m2 override to represent a combined electric + gas equipment load density. If None, equipment.watts_per_area will be used. (Default: None).

Returns:

A text string for a TRACE 700 T.LOAD_MISEQUIP library entry.

dragonfly_trace.exp.internal_loads_from_exp(exp_str)[source]¶

Get Honeybee People, Lighting and Equipment from a TRACE 700 InternalLoadTemplate.

Parameters:

exp_str – A TRACE 700 InternalLoadTemplate entry string.

Returns:

A tuple with three elements.

  • people: A Honeybee People object if people are non-zero and defined per floor area. None otherwise.

  • lighting: A Honeybee Lighting object if lights are non-zero and defined per floor area. None otherwise.

  • equipment: A Honeybee ElectricEquipment or GasEquipment object if miscellaneous loads are non-zero and defined per floor area. None otherwise.

dragonfly_trace.exp.program_from_exp(room_exp_str, internal_loads, airflows, setpoints)[source]¶

Get a complete Honeybee ProgramType from the EXP string of a RoomTemplate.

Parameters:

  • exp_str – A TRACE 700 RoomTemplate entry string.

  • internal_loads – A dictionary of Honeybee internal loads objects with the identifiers of the TRACE 700 InternalLoadTemplate as keys and tuples of 3 Honeybee load objects as values (people, lighting, equipment).

  • airflows – A dictionary of Honeybee airflow objects with the identifiers of the TRACE 700 AirflowTemplate as keys and tuples of 3 airflow objects as values (infiltration, ventilation, exhaust).

  • setpoints – A dictionary of Honeybee Setpoint objects with the identifiers of the TRACE 700 ThermostatTemplate as keys and Honeybee Setpoint objects as values.

Returns:

A Honeybee ProgramType object from the RoomTemplate string.
